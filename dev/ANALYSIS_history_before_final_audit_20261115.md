## Dataset and provenance

The registry in `src/config.py` links each run workbook to its acquisition
session. Current `results/dataset.h5` contains **62 LF acquisitions**, of which
**52 are labelled Glass/Verre or Melt** and ten crystal-bearing. Run01 is an
isothermal series with **five observations at 25 °C**, including the ambient
point added on 8 November. Run01 does not define a heating transition.

Raw acquisitions and workbooks are preserved. Extraction aligns Ruby, Borate
and Tg rows to the Glass master with `(T_C, Pmem, repeated-key occurrence)`.
Unequal sheet lengths must not be zipped by row number. A missing experimental
state or a sensor acquisition absent from the Glass master raises an error.

once each; missing non-reference sensors remain missing.

### Input axes and missing HF

Most glass acquisitions use wavelength in nm. The new
`1bar_25C_Glass_LF.asc` and its background are already in Raman cm⁻¹;
`Run.glass_axis_units` records that exception. Common-axis coverage is validated
before resampling. No second wavelength-to-Raman conversion is applied.

The workbook names `1bar_25C_Glass_HF.asc`, but that file is absent. LF processing
is independent of HF: the LF is retained, while HF stays NaN without a
substitute spectrum. Marker HDF5 stores source filenames, input-axis units and

## Pipeline and reproduction

Use Python ≥3.12 and dependencies from `requirements.txt`. `make all` rebuilds
the main analysis/figure pipeline; `make figures` rebuilds its pressure, peak,
temperature and transition prerequisites. Both accept `PYTHON=.venv/bin/python`.
Optional branches and exports are listed in the root README.

A staged rebuild uses:

1. `python -m src.extract_markers --no-fig`: sensor extraction and glass cleaning.
2. `python -m src.pressure`: pressure conversion, LF Long correction, dataset assembly.
3. `python -m src.peak_fitting`: five-band posterior parameters/covariances and plots.
4. `python -m src.analyse_tg`: conservative exploratory screening.
5. `python -m src.tg_spectra_ruptures`: common one-break search and null tests.
6. `python -m src.manuscript_data`: shared current transition JSON.
7. `python -m src.temperature`: per-acquisition equivalent offsets and Figure 2d statistics.
8. `python -m src.figures.fig7_transitions`: interval fit and full T–P diagnostic.
9. Verify the saved intercept/profile against `src/figure_data.py`; update both
   stored constants if a new regression changes them, then run `python -m src.figures`.

The reference-consistency test and Figure 9 guard against using a stale stored
Tg(0). Figures consume existing upstream results; plotting alone does not
refresh pressure or deconvolution data. `make extract RUNS="run01_20250220_25C"`
restricts extraction, not the full downstream registry.

`python -m src.export_melt` exports the last Melt spectrum before first
crystal-bearing heating acquisition. `python -m src.collect_melt_fits` collects
all current Melt-only fit plots. These are separate from `make all`.

## Pressure scales and uncertainties

`src/pressure_sensors.py` centralizes the **Wei2024 scales for both gauges**,
thermal wavelength shifts and uncertainty propagation. Wavelengths are in nm,
temperatures in K and pressure in GPa. The input temperature is the sample-
temperature estimate; the main pipeline uses the experimental thermocouple
reading without applying a gauge-derived offset correction.

The dataset retains per-grain pressures, medians, counts and descriptive
spreads. `P_std = sqrt(sample_variance + mean(grain_uncertainty²))`; this is
**not the standard error of the median**. Shared calibration errors are not
independent point noise. Reference drift, model discrepancy and cross-step
covariances are not fully characterized. A single measured grain is never
replicated to create a pressure dispersion or increase the sample count.

New calibration scales require published tabulated checks in both directions.
The 8 November update changes measured anchors, not the calibration family.

## Raman preprocessing and deconvolution

Fluorescence peak detection retains its configured width thresholds. Returned
FWHM is measured separately at half the background-corrected peak height, with
interpolated crossings in nm. Borate pressure uses the fitted pseudo-Voigt
center; this measured FWHM sets its initial width, fit window and bounds.
Non-converged pseudo-Voigt fits are counted, warned about and left NaN.
They are not replaced by detected maxima in the pressure calculation.

LF acquisitions are despiked, corrected with their measured background and
placed on the 400–1279 cm⁻¹ common grid. Long correction is applied in the
pressure stage at experimental temperature. A missing HF does not alter LF.
HF processing is separate and does not receive the LF Long correction.

`src.peak_fitting` selects 820–1270 cm⁻¹, subtracts an endpoint linear baseline
and normalizes to the maximum. It fits T–OH, Q², T₂S and Q⁴ Gaussians plus a
Q³ pseudo-Voigt using `lsqfit`/`gvar` Gaussian parameter priors. Parameters are
not hard-bounded; nonphysical posterior means are rejected. Full local
parameter, area and fraction covariances are saved. A failed fit prevents
replacement of the existing active peak-fit file.

All **62** current LF spectra have physical fitted means. The new ambient fit
has structured residuals near its maximum; numerical convergence/physical
means do not independently validate the five-band representation. Positions,
widths, areas and covariance estimates remain conditional on the model, noise,
baseline and priors. Areas/fractions are fitted intensities, not measured Qn
populations. Integrated areas in S3 refer to maximum-normalized spectra; they
are not fractions or absolute scattering intensities.

## Spectral-change searches and identifiability

`src.tg_spectra_ruptures` searches one common split with separate linear segments
in five equally weighted feature families: four Raman PC scores, LF/HF-region
area ratio, selected Qn ratios, five band positions and sensor channels.
Here the Raman area ratio means **400–830 / 830–1270 cm⁻¹**, not the separate
3000–4000 cm⁻¹ OH acquisition. At least three observations per segment are
required. The default fit selection is non-crystallized heating at **T ≥150 °C**;
`--t-min` overrides it. A one-break solver always returns a partition when
there are enough observations; this alone is not evidence for a transition.

The inherited global Raman PCA trains on all 62 acquisitions, including the
ambient, recheck and crystal-bearing spectra, before selecting fit points.
All Raman and sensor PCAs use `random_state=0`; automatic solver selection
is retained. Global sensor PCA uses means of actually measured finite grain spectra.
Missing grains are excluded; steps without measured shapes remain missing.
One grain can define a mean shape, but its inter-grain shape dispersion is NaN.
Adding the ambient acquisition can therefore change PCA channels and null-test
statistics even though it is excluded from the ≥150 °C split search.

Linear and quadratic continuous nulls each receive 999 residual permutations
(seeds 0/1), with the best split re-searched on each draw. A split is supported
under this procedure only if both p-values are below 0.05. The procedure is
exploratory, has no across-run multiplicity correction, assumes conditional
residual exchangeability and does not demonstrate physical Tg.

Current brackets for Runs 2–6 are 262–286, 270–277, 256–262, 313–332 and
300–306 °C. Their midpoints are 274, 273.5, 259, 322.5 and 303 °C. Run 3 remains
a candidate. Brackets are adjacent observed acquisitions, not confidence
intervals. First crystal-bearing heating acquisitions occur at 322, 314, 291,
369 and 345 °C; these are first observations, not exact physical onset times.
See `results/manuscript_transitions.json` for current values and source indices.

Pressure, temperature, membrane interventions and loading effects may be
confounded. The independent `test_hypo_tg/`, `test_bayesian_tg_2d/`,
`test_raman_trajectories/` and `test_structure_crystallization/` reports retain

Legacy `src.figures.fig5_run2` uses historical annotations; the registered

## Linear extrapolation and limiting fictive-temperature comparison

`src.tg_pressure_regression.fit_interval_line` fits **T = a + bP** to the five
observed temperature brackets. A normal latent mean plus fitted between-run
scatter is integrated over each interval; no uniform event distribution or
Gaussian half-bracket error is assumed. The pressure-spread sensitivity uses
the maximum endpoint P_std and half the endpoint pressure drift in quadrature.
This is an explicit Gaussian proxy, not a calibrated median-pressure error.
Thermocouple error-bar half-width is **±2 K**.

Current results: **a = 239.7332 °C**, **b = 6.92920 °C/GPa**; the approximate
95% intercept profile support is **[210.8623, 270.6225] °C**. The threshold is
Δ(−2 log L) = 3.84146. Support is conditional and asymptotic, uncalibrated for
exact coverage with five runs; it is not a new-acquisition prediction interval.
The central reference and bounds are stored in `src/figure_data.py`. The
independent limiting fictive-temperature reference is stored in `src/config.py`:
**219 ±4 °C at 25 K/min**, for the as-received ANN +5 wt% H2O glass after
piston-cylinder synthesis, subsequently loaded into the DAC. Figure 7 shows
this single point at ambient pressure (plotted at 0 GPa) as “T_f' at 25 K/min”,
replacing both previous DSC peak markers. The confidence level of ±4 °C was
not specified; it is drawn as supplied. This reference does not anchor or
otherwise change the spectral regression.

## Temperature diagnostics

`src.temperature` solves paired-gauge agreement separately for each acquisition,
using measured median line positions and the existing Wei2024 calibrations.
The output is an **equivalent offset conditional on the references and pressure
equations**, not independent sample thermometry or a correction to apply.
All 62 acquisitions retain equal weight. Figure 2d reads `dT_step_K` from
`results/temperature_steps.csv`; `results/temperature_summary.json` records
mean, median and empirical central 68.27% bounds (quantiles Φ(-1), Φ(+1)).
These bounds describe the spread of offsets, not confidence in their mean.
The module no longer performs per-run regressions, bias-model comparisons or
separate diagnostic plots. No old model output is needed for the manuscript.
